# Homework JSON API

## Функциональность проекта

Программа предназначена для работы с банковскими транзакциями.

### Работа с файлами

Программа поддерживает чтение финансовых операций из:

* JSON-файлов;
* CSV-файлов;
* Excel-файлов.

Для обработки CSV- и Excel-файлов используется библиотека `pandas`.

### Фильтрация операций

Реализована фильтрация банковских операций по статусу:

* `EXECUTED`;
* `CANCELED`;
* `PENDING`.

Регистр введённого пользователем статуса не имеет значения.

Также доступна фильтрация только рублёвых операций.

### Поиск операций

Реализован поиск банковских операций по заданному слову в поле `description`.

Для поиска используется библиотека `re`, поэтому поиск выполняется с использованием регулярных выражений.

### Подсчёт категорий

Реализована функция подсчёта количества банковских операций по заданным категориям.

Для подсчёта используется `Counter` из библиотеки `collections`.

### Сортировка

Операции можно отсортировать по дате:

* по возрастанию;
* по убыванию.

### Форматированный вывод

Реализован форматированный вывод банковских операций с отображением:

* даты;
* описания операции;
* отправителя и получателя;
* суммы;
* валюты.

Если после фильтрации не найдено ни одной операции, программа выводит соответствующее сообщение пользователю.
